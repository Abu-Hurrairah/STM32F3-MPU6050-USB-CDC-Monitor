# GitHub Upload Setup

## Repository name

```text
STM32F3-MPU6050-USB-CDC-Monitor
```

## Description

```text
STM32F3 embedded C project for MPU6050 6-axis IMU acquisition over I2C with raw/scaled sensor processing and USB CDC Virtual COM output.
```

## Create the GitHub repository

Use:

```text
Visibility: Public
Add README: Off
Add .gitignore: None
License: No license
```

Then upload the **contents of this extracted folder**, not the ZIP file itself.
